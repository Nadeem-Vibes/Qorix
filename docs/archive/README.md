# Archive

This folder keeps historical records that are useful as evidence but are not
part of the current documentation. Filenames describe the subject rather than
the development phase that produced them.

## Mod platform

The `mod-platform/` records follow the platform from feasibility through the
hardening gate:

- [feasibility.md](mod-platform/feasibility.md) — initial feasibility study.
- [probe-report.md](mod-platform/probe-report.md) — Lua runtime probe results.
- [contracts.md](mod-platform/contracts.md) — early error and API contracts.
- [mod-core-plan.md](mod-platform/mod-core-plan.md) — plan for the mod core.
- [mod-core.md](mod-platform/mod-core.md) — mod core gate record.
- [api-and-partial-ui.md](mod-platform/api-and-partial-ui.md) — API and partial
  UI gate record.
- [api-reference-phase2.md](mod-platform/api-reference-phase2.md) — API
  reference at the API/partial-UI gate.
- [shell-and-learning.md](mod-platform/shell-and-learning.md) — shell and
  learning engine gate record.
- [api-reference-phase3.md](mod-platform/api-reference-phase3.md) — API
  reference at the shell/learning gate.
- [reference-course.md](mod-platform/reference-course.md) — reference course
  gate record.
- [reference-course-screenshots.md](mod-platform/reference-course-screenshots.md)
  — screenshot notes from the reference course.
- [developer-preview.md](mod-platform/developer-preview.md) — Developer Preview
  gate record.
- [distribution-security.md](mod-platform/distribution-security.md) —

- [hardening.md](mod-platform/hardening.md) — public 1.0 hardening gate record.
